# Bursa Kâşifi

**Bursa'yı keşfet, kodla, oyunla öğren!**

Bursa'nın değerlerini kodlama ile oyun oynayarak öğreten, tarayıcıda çalışan bir EU Code Week etkinlik sitesi.

- 6 kodlama oyunu + bonus oyun (sıralama, örüntü, döngü, koşul, ikili kod, algoritma, hata ayıklama), her birinde 3 seviye
- Kendi Bursa rotanı tasarla ve kodunu arkadaşınla paylaş
- Kâşif pasaportu, rozetler ve adına özel sertifika (PNG / PDF)
- Bursa'nın hazineleri ve kültürümüzün değerleri

Kurulum gerektirmez: `index.html` dosyasını açmanız yeterlidir. GitHub Pages ile yayınlamak için **Settings → Pages → Branch: main / (root)** seçin.
